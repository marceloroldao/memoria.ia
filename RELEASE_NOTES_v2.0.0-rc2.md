## Candidate scope

Post-RC1 R1–R14 integrates persistent occurrence-local structural trajectories,
stable evolving addresses, hierarchical composition, branch outcomes, competing
attractors, witnessed and revocable structural equivalence, explicit temporal
current/previous/history/change, and a unified read-only inference surface.
The Context Compiler v2 emits a structured cognitive packet with uncertainty,
conflicts and provenance. Generated claims remain candidates until an explicit
evidence-bearing admission. The versioned cognitive ABI indicates local,
server and model origin. StructuralEvent and RealitySlice carriers converge
on the trajectory substrate.

The controlled R14 benchmark completed 5/5 structural/temporal cognitive cases
before language generation with zero LLM and external calls. This measures the
address-level cases in the gate, not general natural-language reasoning.

## Validation

The cross-repository gates on PR #361 passed with the published BDR RC4 pin:
Android host and arm64, shared-handle cold reopen, full product tests, Docker
build, persistent container restart, backup/restore, R14 benchmark and RC1
metadata preservation. See `docs/V2_RC2_FREEZE_RECORD.md` for exact runs,
the skipped experimental gate and publication conditions.

## Scope limits

- Structural equivalence is witnessed on observed signatures; unseen lexical
  paraphrases are not established.
- Exact timing within a RealitySlice is preserved but is not yet consumed by
  the R8 attractor.
- The raw retrieval comparison is not a full RAG benchmark.
- OFF.IA natural-language end-to-end integration remains a separate gate.
- No production security certification or general replacement of LLMs is claimed.

The functional freeze and release scope are fixed above. The public tag must
point to the validated publication commit. The RC2 DOI may be added only after

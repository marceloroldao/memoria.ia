# Resolutive Science compatibility

This repository follows the governance requirements of the Resolutive Science ecosystem without claiming compatibility with a specification version that has not been formally published.

Current references:

- Resolutive Science repository baseline: `resolutive-science` v0.1.1
- Project governance baseline: RSPS 1.0-draft
- RSMS compatibility: pending a formally numbered RSMS release in `resolutive-science`

## Terminology discipline

The project uses resolutive terminology only where it maps to computational constructs explicitly defined in this repository. Computational results, engineering benchmarks and experimental hypotheses remain distinct from physical claims.

If a future numbered RSMS introduces a conflicting definition for a shared term, symbol or identifier, this repository must either migrate to the normative definition or document and version the deviation before a stable v1.0 release.

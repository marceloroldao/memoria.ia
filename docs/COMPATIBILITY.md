# Resolutive Science compatibility

This repository follows the governance requirements of the Resolutive Science ecosystem without claiming compatibility with a specification version that has not been formally published.

Current references for Memoria.ia `v1.0.0-rc1`:

- Resolutive Science published baseline: `resolutive-science` v0.2.0
- Project governance baseline: RSPS 1.0-draft
- RSMS compatibility: `1.0-rc.1`

## Release-candidate boundary

Memoria.ia `v1.0.0-rc1` intentionally remains a release candidate while its normative memory-system compatibility target is also a release candidate.

Before promoting Memoria.ia to final v1.0, this declaration must be re-audited against the stable RSMS specification. If stable RSMS changes a shared term, contract, symbol or identifier, Memoria.ia must either migrate to the normative definition or explicitly document and version the deviation before final v1.0 publication.

## Terminology discipline

The project uses resolutive terminology only where it maps to computational constructs explicitly defined in this repository. Computational results, engineering benchmarks and experimental hypotheses remain distinct from physical claims.

The software release status does not imply experimental validation of Resolutive Physics or any broader physical theory.

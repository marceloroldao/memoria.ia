# memoria.ia v1.0.0-rc2

Release date: 2026-09-02

Archival DOI: [10.5281/zenodo.22244038](https://doi.org/10.5281/zenodo.22244038)

## Scope

This second v1.0 release candidate extends the published RC1 baseline with:

- durable Retrieval v2;
- provenance-aware relational memory;
- episodic continuity;
- explicit resolution modes;
- bounded deterministic two-hop resolutive inference over typed transitive relations;
- PC/server and Android-compatible local-first runtime boundaries.

Memoria.ia remains the authoritative owner of memory semantics, state, relations, provenance, trajectories and context selection. Resolutive-DB/BDR remains the durable persistence layer. Language models remain optional consumers.
